# GraphLab 3D

Mini 3D graphing calculator berbasis Python Flask, HTML, dan CSS.

Contoh input:
- `z = x^2 + y^2`
- `z = sin(x) + cos(y)`
- `z = x^2 - y^2`
- `z = sqrt(x^2 + y^2)`
- `z = 2sin(x)cos(y)`

Install:
`python -m pip install -r requirements.txt`

Run:
`python app.py`

Buka `http://127.0.0.1:5000`.
